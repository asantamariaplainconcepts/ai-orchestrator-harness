# The specs of the first product

`specs-v1/` holds the 76 capability specs of the product this repository built before v2: the task
inbox over four vendors, the folder screen with its tabs, the World seams, the controlled workflows,
the watcher and the `issue-loop.yaml` loop. `changes-v1/` holds the two changes that were still open
against them. The code they describe was deleted by #542, and #518 retired them here rather than
leaving them in `openspec/specs/`, where a delta would be written against something that no longer
exists. They are kept as a record and nothing reads them; the capabilities of the product that exists
now are in `openspec/specs/`, and the archived changes that built the first product stay in
`openspec/changes/archive/`.
